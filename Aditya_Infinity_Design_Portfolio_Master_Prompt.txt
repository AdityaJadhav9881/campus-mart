4. COLOR / TYPE / SPACING
============================================================

Foundation:
Deep black
Deep navy
Dark neutral surfaces

Text:
Near-white primary
Muted gray secondary

Accents:
Cyan
Controlled blue

Green = semantic success/healthy state only.
Red = actual critical/error state only.

Do not use green everywhere.

Use a premium modern sans-serif.
Avoid unreadable futuristic fonts.

Spacing:
4px / 8px base system.

Preferred:
8, 12, 16, 24, 32, 48, 64, 96

Check symmetry, margins, baseline alignment, section spacing,
text-to-button spacing, image-to-text spacing and navigation spacing.

Use generous negative space.

============================================================
26. MOTION
============================================================

Animation should communicate:
- Where something came from
- Where it went
- What changed
- What is important

Do not animate for decoration alone.

Typical timing:
Fast: 100–180ms
Normal: 200–350ms
Emphasis: 400–700ms
Major transition: 500–1000ms

Never make the user wait for animation.
